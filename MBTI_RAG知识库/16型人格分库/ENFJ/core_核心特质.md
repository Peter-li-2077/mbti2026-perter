# ENFJ 核心特质

## 基本描述
ENFJ，即主人公型人格，是热情的领导者和激励者。他们对他人有深度关怀，善于鼓舞和引导他人，有强烈的责任感，希望帮助他人成长和发展。

## 主导功能：外倾情感 (Fe)
- 关注他人情感和需要
- 促进和谐和连接
- 社交感知和同理心
- 照顾和培养他人

## 辅助功能：内倾直觉 (Ni)
- 洞察模式和可能性
- 未来愿景和远见
- 理解复杂的人际动态
- 追求意义和目的

## 第三功能：外倾感觉 (Se)
- 当下现实和环境
- 行动导向
- 适应变化

## 第四功能：内倾思考 (Ti)
- 逻辑分析和批判性思维（发展中）
- 客观评估
- 构建理解框架

## 核心特征
- 热情、关心他人，有同情心
- 善于激励和领导他人
- 有强烈的责任感和使命感
- 善于理解他人的需要和潜力
- 可能过度照顾他人，忽视自己
- 社交能力强，善于协调
